# AudioBug

AudioBug is a plugin for JetBrains IDEs that provides non-visual editor feedback to those using a screen reader.
Inspired by the accessible feedback in Visual Studio and Visual Studio Code, it brings a similar experience to JetBrains
IDEs.

## Requirements

- IntelliJ Platform 2025.3 or later
- Active screen reader
- Gradle 9.5.0 or later (if building from source)

### Tested With

- NVDA 2025.3.2-2026.1.1 
- JAWS 2024
- VoiceOver (macOS 26.6)
- Rider, IntelliJ IDEA, CLion 2026.2 

## Key Features 

- Automatic Diagnostic Announcements - Sound cues and spoken feedback for errors and warnings associated with the current line.
